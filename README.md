# ZEYPHRA website

Two-page React website built with Vite. The ReactBits `BlurText` and `Magnet` components are installed from the ReactBits registry into `src/components/` and can be edited locally.

## Run locally

```sh
npm install
npm run dev
```

The home page is `/` and the business page is `/business.html`. Run `npm run build` to create the static site in `dist/`.

The beta dialog is a front-end prototype. It validates and confirms locally without transmitting or storing form details.
